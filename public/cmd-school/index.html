CORE COMMANDS

initialize_system
Bootstrap RUNE orchestration layer. Initializes agent registry and state management.
spawn_agent --type [agent_type]
Spawn a new agent instance. Types: genesis, harvest, package, terraform, conductor.
query_state --agent [name]
Retrieve current state from a specific agent or global state.
dispatch_task --to [agent] --task [spec]
Send a task to an agent with JSON specification.
list_agents --status [active|idle|error]
List all agents with optional status filter.
monitor --real-time [true|false]
Open real-time monitoring dashboard for all agents.

ANALYSIS COMMANDS

analyze_decisions --range [start:end]
Analyze decision logs within a specified range. Example: --range 100:200
trace_execution --agent [name] --task [id]
Trace the execution path of a specific task through all agents.
generate_report --type [performance|decisions|utilization]
Generate analysis reports on system performance or agent activity.
export_data --format [json|csv] --dest [path]
Export orchestration data in specified format.
