OPERATING PRINCIPLES

SHIP DAILY

Theory is cheap. Production is truth. Every day ends with something deployed, documented, or demonstrably improved.

PARALLEL OVER SEQUENTIAL

Why ask one model when you can ask four? Consensus beats authority. The best idea wins, regardless of source.

CONTEXT IS KING

An AI without context is just expensive autocomplete. We invest heavily in context architecture—handover docs, state persistence, memory systems.

COST-AWARE, NOT COST-OBSESSED

Use the right model for the job. Tier 1 for decisions, Tier 2 for execution, local models for iteration. Every token justified.

DOCUMENT EVERYTHING

R&D logs aren't bureaucracy—they're institutional memory. Contemporaneous evidence. The trail that proves the work happened.

STAY DANGEROUS
