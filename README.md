# RUNE Digital Studio - Landing Page

Welcome to the RUNE Digital Studio landing page repository. This project showcases our Multi-Agent AI Orchestration Platform with interactive demonstrations.

## Overview

RUNE Digital is a Multi-agent AI orchestration platform featuring:
- 11+ specialized AI agents with tier-based coordination
- Local LLM inference on RTX GPU
- Vertex AI integration with Gemini 1.5 Pro
- Real-time metrics and decision audit trails

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Development

This project uses:
- **Vite** for fast development and building
- **React** for UI components
- **Three.js** with React Three Fiber for 3D visualizations
- **React Three Drei** for helpers and abstractions

### Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build for production (also runs post-build processing)
